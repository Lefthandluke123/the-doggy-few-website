Accessibility of this website

We want everyone to be able to use this site: including people with low vision, people working with a screen reader and people who do not use a mouse. Below is what we have done and what could still be better.

What has been done

  • Every photograph has a description in words, so a screen reader can say what is in it.
  • The whole site can be operated from the keyboard. At the very top there is a link that skips the menu.
  • Headings follow a logical order and form fields have a name.
  • The site exists in Dutch, English and German, and the language is marked in the code so a reading voice picks the right pronunciation.
  • Photographs that are purely decorative are skipped rather than read out twice.

What could still be better

The site has not been audited by an independent agency, and not every page has been walked through with a screen reader. In a few places the contrast between text and background is tighter than the guideline recommends. We fix these as we come across them.

Run into something?

Let us know at info@doggyfew.com or call +31 6 53 71 62 49. We will put it right; a band’s website should work for everyone.

This statement applies from 21 August 2026. We aim for the WCAG 2.1 guideline, level AA. As a small band we do not fall under the European Accessibility Act, but we keep to the same agreements as far as we can.
